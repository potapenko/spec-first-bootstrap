# Project Migration Launch Prompts

These prompts start restartable Markdown-first migrations in fresh Codex tasks.
Open the new task at the named target repository root and paste the complete
project prompt. Do not run several project migrations in one task.

## Prompts

- [HoldType Swift](holdtype-swift.md) — large 54-document corpus; begin with a
  single pilot batch selected from the existing registry.
- [SwiftUI Semantic Audit](swiftui-semantic-audit.md) — compact authoritative
  package whose `tz-v5` meaning and accepted addenda must remain unchanged.
- [CodexSwitch](codex-switch.md) — small corpus missing a Markdown root; current
  Git-ahead state requires a push-safety preflight.

## Operating boundary

The embedded census figures are planning snapshots, never current authority.
Every new task repeats the mechanical census without printing document bodies,
presents checkpoint 0, and waits for approval before writes. Conversion then
continues one bounded semantic batch at a time with Markdown migration state.

The canonical shared workflow remains
[`../migrate-legacy-spec-library.md`](../migrate-legacy-spec-library.md).
